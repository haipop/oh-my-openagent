# Install OmO for a supported host

The `feat/deepseek-harness` branch ships host plugins, not a standalone Pi/Senpi agent. Docker is not required to install or run them.

Use the [fork README](https://github.com/haipop/oh-my-openagent/blob/feat/deepseek-harness/README.md) for supported hosts and step-by-step installation and removal instructions.
